# E-Commerce Sales & Customer Analytics

## 📊 Project Overview

This project analyzes e-commerce sales and customer data to identify sales trends, customer behavior, product performance, and country-wise revenue.

The project combines **SQL, Python, and Power BI** to perform data cleaning, exploratory data analysis, business analysis, and interactive dashboard visualization.

---

## 🎯 Objectives

- Analyze overall sales performance
- Identify revenue trends over time
- Analyze customer distribution
- Identify top-performing products
- Compare revenue across countries
- Analyze monthly sales and quantity trends
- Build an interactive Power BI dashboard
- Generate business insights from the data

---

## 🛠️ Tools & Technologies

- **Python**
  - Pandas
  - Matplotlib
  - Jupyter Notebook

- **SQL**
  - MySQL

- **Power BI**
  - Power Query
  - DAX
  - Interactive Dashboard

  - Dataset storage and preprocessing
